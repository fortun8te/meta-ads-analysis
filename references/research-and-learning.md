# Research and learning

## Research to resolve a question

Identify what the current ad, results and existing brand evidence cannot answer. Search for those gaps. More collected ads do not automatically improve a decision. Separate own-account measurement, competitor references, customer evidence, practitioner advice and product substantiation.

For public competitor research, use authorized Ad Library access, public pages or public source material. Record source URL/ad-library ID, advertiser/page identity, dates/country/filters, media/copy coverage and inspected landing page. Inspect actual creative rather than titles or descriptions. Public persistence, repeated creatives, engagement, reach or estimated spend do not reveal purchase CPA/ROAS/profit. Treat longevity as a persistence clue and competitor angles as reference hypotheses. Preserve library coverage limits and do not confuse unavailable media with an inactive ad.

A search hit or archive label is a lead until the actual advertiser and media are verified. Count only inspected references as inspected; keep inaccessible cards, product-page imagery and campaign films separately labeled. A matching title can still open the wrong advertiser.

Choose an available authorized competitor source: existing archives, public Ad Library/pages, or an installed research tool. Tool scores and estimates remain public proxies. Check current project status before using a collector; a disabled collector stays disabled unless the user explicitly authorizes restarting it. Missing tooling does not block own-account analysis. Record test outcomes in the project's existing ledger; use a tool-specific calibration store only when that workflow is active and its write is authorized.

Use primary documentation for metric/platform behavior and actual research papers for formal causal claims. Vendor/practitioner frameworks can supply methods and questions; their predicted scores, algorithm theories and case studies are not validated predictions for this account. Batch independent source checks within the available service limits. If one source fails, try a genuinely different authorized route before declaring the evidence unavailable. Delegation is optional; keep ownership of interpretation clear.

Keep private data local. Public research queries can describe a general methodological question; they should not contain private results, customer text, signed media URLs or credentials. Use existing authorized access for customer evidence, with question/thread context and source dates. A handful of comments does not establish prevalence or market-wide demand.

## Know what the knowledge bank actually contains

Search the existing topic/card index for the decision, then open only the matching original passage. Retain author/role, date, evidence type and conflicts. Distinguish a teaching, an example shown by a speaker, inspected screen/media evidence and an independently measured result.

A complete transcript inventory does not establish complete attachment or prompt coverage. When a recommendation depends on a referenced document, exercise, screenshot or model recipe, check whether the actual item is available and inspected, only mentioned, inaccessible or outdated. Keep its original locator and current status in the existing source manifest or research note. A course summary is not a recovered prompt, and speech alone does not capture an unspoken interface demonstration. Use an independent brief when a template is unavailable; label the substitute and retrieve the original only through available authorized access.

Reuse verified brand facts, bounded customer evidence, approved references and successful production recipes from their existing locations. Select the relevant slice for the current task, including its gaps and freshness. Do not copy a whole course, book or private dataset into every prompt, create a second knowledge database, or publish private source text to make a workflow portable.

## Learn without repeating work

Maintain a compact ledger for useful findings:

`finding_id, question, source_type, source_refs, account/ad/creative/asset IDs, report_window, attribution, inspected_scope, observation, explanation, alternative, proposed_test, current_status, later_result, next_action`

Keep preference/production acceptance separate from measured performance. Preserve source attribution and conflicting advice. Append later outcomes rather than revising the old observation into a certainty it did not have. Use the project's existing ledger/schema and current context guidance when available; otherwise save a dated local artifact. Avoid writing every routine lookup into permanent guidance.

When revisiting a question, retrieve matching prior observations and their actual sources. Reuse immutable media inspection by checksum and scope, then refresh the necessary results. Keep launch, source creation, report and collection dates distinct. Current user instructions supersede old tasks; history informs reasoning without granting execution permission.
